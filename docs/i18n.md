# 国际化（vue-i18n）开发规范

> 适用项目：`portdistance-m-app`（Vue 3 + Ionic 9 + Capacitor，全球用户）
> 目标语言：`zh-CN`（简体中文）、`en-US`（English）；架构支持继续追加语言。

## 1. 目录结构

```
src/i18n/
  index.ts                 # 唯一的 vue-i18n 实例（Composition 模式）+ 纯 TS 用的 t()
  format.ts                # 语言感知的日期/数字格式化（不要再用 toLocaleString('zh-CN')）
  locales/
    meta.ts                # 支持语言注册表、默认/回退语言、持久化 key
    zh-CN/                 # 命名空间文件（与 en-US 结构必须完全一致）
      index.ts             # 聚合所有命名空间
      common.ts            # 公共词条（保存/取消/加载…）
      tabs.ts              # 底部 tab、离线横幅
      language.ts          # 语言切换页
      errors.ts            # 网络/接口兜底错误
      auth.ts  profile.ts  distance.ts  ships.ts  legacy.ts  report.ts
      map.ts → map/{core,layers}.ts
      budget.ts → budget/{editor,pages,list,detail,map}.ts
    en-US/                 # 同上，英文
```

命名空间文件按功能拆分，避免多人同时改一个文件；运行时 key 前缀见下表：

| 文件 | 运行时前缀 | 负责范围 |
| --- | --- | --- |
| `common.ts` | `common.*` | 全站公共词条、单位 |

## 2. 组件里怎么用

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
const { t, locale } = useI18n()
</script>

<template>
  <ion-title>{{ t('profile.account.title') }}</ion-title>
  <ion-input :placeholder="t('auth.email.placeholder')" />
</template>
```

- 需要随语言变化的查表（tab 列表、任务类型映射等）必须放在 `computed(() => ...)` 或函数内部，
  **禁止**在 `.vue` 模块顶层调用 `t()`。
- 纯 TS（store / api / utils）：`import { t } from '@/i18n'`，在函数/取值时调用，**禁止**模块顶层调用。

## 3. 文案编写要求

- `zh-CN` 保留原有中文口径；`en-US` 用专业航运英语，历史项目已有译法时优先复用
  `portdistance-mobile-lite/src/i18n/lang/en.ts`。
- 消息文件只允许「嵌套对象 + 字符串」，**不允许数组、函数、`as const`**。
- 插值统一 `{name}`；能整句表达就不要拼接片段（英文语序与中文不同）。
- **`|` 是 vue-i18n 的复数分隔符**：文案里需要竖线时必须转义为 `{'|'}`，
  例如 `portLine: "{index}. {name} {'|'} {task} {'|'} {distance} nm"`，否则只会渲染出第一段。
- `zh-CN` 与 `en-US` 的具名插值必须一一对应（`npm run i18n:check` 会校验）。
- 单位：优先整句 key，例如 `totalDistance: '全部航程 {value} 海里'` / `'Total distance {value} nm'`；
  零散单位用 `common.unit.*`。

## 4. 术语表（不翻译 / 固定译法）

- 不翻译：`LSFO`、`HSFO`、`MGO`、`LSDO`、`ECA`、`DWT`、`ETA`、`ETD`、`IMO`、`PDF`、`PortDistance`、
  `IHO`、`JWC`、`S-23`、`JWLA-034`、`VLIZ`、`Marine Regions`、`Skype`、`WeChat`，以及港口名、公司名、人名、
  已是拉丁字母的海区/国家名。
- 常用固定译法：满载 laden · 空载/压载 ballast · 主机 main engine · 辅机 auxiliary engine ·
  在港闲置 idle in port · 在港作业 working in port · 日油耗 daily fuel consumption · 经济航速 eco speed ·
  全速 full speed · 港序 port rotation · 航段 leg · 航路点 waypoint · 转向点 turn point ·
  路由点 route point · 抗风浪余量 weather margin · 等泊 waiting for berth · 港口使费 port charges ·
  扫舱费 hold cleaning · 通讯娱乐伙补 communication, entertainment and crew allowance · 滞期费 demurrage ·
  速遣费 dispatch · 回扣佣金 address commission · 经纪佣金 brokerage · 总距离 total distance ·
  航行天数 sailing days · 在港天数 days in port · 航次天数 voyage days · 总收入 total income ·
  净收入 net income · 营运成本 operating cost · 总费用 total expenses · 经营利润 operating profit ·
  净利润 net profit · 日租金 hire per day · 日租金水平 hire level per day · 日均利润 average daily profit ·
  未命名 unnamed · 草稿 draft · 余量 margin

## 5. 不要国际化的内容

代码注释（保持中文）、API 路径、请求参数/枚举值（`'load'`/`'eco'`/`'percent'` 等）、存储 key、
CSS 类名、地图/地理数据标识、后端返回的 `msg`（服务端文案原样透出）。

## 6. Ionic 组件自带文案

```vue
<ion-datetime :locale="locale" />                                     <!-- 月份/星期 -->
<ion-select :ok-text="t('common.ok')" :cancel-text="t('common.cancel')" />
<ion-searchbar :cancel-button-text="t('common.cancel')" />            <!-- 有取消按钮时 -->
<AppBackButton default-href="/tabs/profile" />                        <!-- 替代 ion-back-button -->
```

`AppBackButton`（`src/components/AppBackButton.vue`）是 `ion-back-button` 的封装：
Ionic 只在启动时读取一次 `backButtonText`，所以必须用组件显式绑定 `text` 才能跟随语言切换。
用法：把 `<ion-back-button default-href="…" />` 换成 `<AppBackButton default-href="…" />`，
外层 `<ion-buttons slot="start">` 保持不变。

## 7. 日期与数字

```ts
import { formatAmount, formatDate, formatDateTime, formatNumber } from '@/i18n/format'

formatDateTime(row.updateTime, t('common.notSet'))   // 2026/07/29 14:05 或 07/29/2026, 14:05
formatAmount(1234.5)                                 // 1,234.5
```

禁止在业务代码里写死 `toLocaleString('zh-CN')`、`Intl.NumberFormat('en-US')`。

服务端需要按语言生成内容时（如邮箱验证码模板），用 `apiLanguage()` 取后端约定的语言码（`'zh' | 'en'`）：

```ts
import { apiLanguage } from '@/i18n'
await sendAccountEmailCode({ email, language: apiLanguage(), scene: 2 })
```

## 8. 校验命令

```bash
npm run i18n:check   # key 一致性 + 占位符一致性 + 未迁移中文 + 硬编码 locale + 裸 | 分隔符
npm run i18n:smoke   # 运行时冒烟：真实加载 vue-i18n 实例，验证取值/插值/语言切换
npm run typecheck    # vue-tsc -b
npm run build        # 完整构建
```

`i18n:check` 会：
1. 校验 `zh-CN` 与 `en-US` key 路径完全对称、值非空字符串且在源码中可解析；
2. 校验同一 key 在两个语言里的具名插值集合一致；
3. 校验消息里没有未转义的裸 `|`（会被 vue-i18n 当复数分隔符）；
4. 校验源码中出现的 `t('…')` 字面量 key 都真实存在；
5. 扫描 `src/` 非 locale 文件中残留的中文（注释除外）；
6. 标记写死 locale 的 `toLocaleString('xx-XX')` 调用。

## 9. 新增语言

1. `locales/meta.ts` 的 `SUPPORTED_LOCALES` 增加条目（`code` / `nativeName` / `englishName` / `htmlLang` / `dayjsLocale` / `apiLanguage`）；
2. 复制 `locales/en-US/` 为新语言目录并翻译；
3. `src/i18n/index.ts` 的 `messages` 注册；
4. `npm run i18n:check` 与 `npm run i18n:smoke` 必须通过。

语言解析优先级：用户选择（`appStorage` key `pd.app.locale`，取值 `system | zh-CN | en-US`）
→ 设备语言（`navigator.languages` 前缀匹配）→ `DEFAULT_LOCALE`（当前 `en-US`）。
`initLocale()` 在 `main.ts` 挂载前执行，并同步 `document.documentElement.lang` 与 dayjs locale；
选择「跟随系统」时监听 `languagechange` 自动切换。

# 工作流协作规则（子任务执行者必读）

每个工作流**只允许修改自己名下的文件**（消息文件 + 源码文件），不要改动
`src/i18n/index.ts`、`src/i18n/format.ts`、`src/i18n/locales/meta.ts`、
`common.ts`、各 `index.ts` 聚合文件，也不要动其他工作流的源码文件。

## 消息文件规则

- 只写「嵌套对象 + 字符串」；不要数组、函数、`as const`。
- 文件内 key 通过聚合后由前缀访问，例如在 `zh-CN/auth.ts` 里写 `title: '账号登录'`
  运行时就是 `t('auth.title')`。
- 两个语言文件必须一一对应，key 集合完全一致。
- 用 `// 页面/区块` 短注释分组。

## 源码改造规则

1. `.vue`：补 `const { t } = useI18n()`；模板与脚本内用 `t('…')`；需要 `locale` 时一并解构。
2. `.ts`：`import { t } from '@/i18n'`，调用点放在函数/取值时。
3. 模板文本、`label`、`placeholder`、`title`、`aria-label`、`alt`、Toast/Alert/Loading 文案、
   `throw new Error(...)` 的用户可见文案，全部要翻译。
4. `ion-back-button` → `AppBackButton`；`ion-datetime` 加 `:locale="locale"`；
   `ion-select` 加 `ok-text` / `cancel-text`；`ion-searchbar` 有取消按钮时加 `cancel-button-text`。
5. 日期/数字改用 `@/i18n/format`。
6. 不要重命名导出、props、事件、路由，不要改变组件行为（本任务只做文案 + locale 适配）。
7. 注意 `tsconfig.app.json` 开启 `noUnusedLocals`/`noUnusedParameters`：清理未使用的 import/变量。
